# Antithesis Documentation

> Antithesis is an autonomous software testing platform that finds deep bugs using deterministic simulation and continuous fuzzing. This is the index of the documentation; each entry links to the page's raw-markdown (.md) form.

- [Using Antithesis with AI](https://antithesis.com/docs/introduction/using_antithesis_with_ai.md): Leverage AI to get answers to your burning Antithesis related questions. Build fast and test faster using Antithesis.
